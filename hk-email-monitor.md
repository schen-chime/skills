# HK email monitor

Use [hk-trend-monitor](hk-trend-monitor.md) and its [complete installable skill bundle](hk-trend-monitor/SKILL.md). The new workflow requires a date and 24-hour time, defaults to `America/Chicago`, returns separate recorded/proposed user lists, and includes the lower-priority Play Integrity/unlock risk tracker.

Install the entire `hk-trend-monitor/` directory. The old no-input, latest-72-hour workflow is superseded.
